## Justificativa e escolha
**Escolha: GitHub Pages.** O site é estático, então o GitHub Pages atende sem custo e entrega o site com HTTPS automático. O Impacto Verde foi publicado nele. Para o domínio, o .com.br no Registro.br tem preço fixo e é fácil de renovar.
